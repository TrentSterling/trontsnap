# Shot list

The README and landing page have slots waiting for these. Capture them with
TrontSnap itself, save into this folder with these exact names, then
un-comment the image lines at the top of `README.md`.

Use a good theme (roll the randomizer until one pops) and a gallery view that
does not show anything private: the filter chips + search make it easy to
frame a safe slice, or seed a scratch `Pictures\TrontSnap` first.

| File | What it shows | Used by |
|---|---|---|
| `hero.png` | Main window, Gallery tab, grid full of thumbnails, search box visible, ~1400px wide | README hero |
| `demo.gif` | THE four-second pitch: press PrtSc, toast pops with the preview, drag the toast into a Discord message. One take, tight crop | README + landing hero |
| `editor.png` | The annotation editor mid-edit: one arrow, one box, one solid redaction over fake text | README (add with the others) |
| `theme.gif` | The title-bar swatch opened, randomizer hammered 5 or 6 times, text staying readable every roll | Landing page (the engine pitch lands better animated) |
| `ocr.png` | A region drag over some code + the pasted text beside it (split shot or before/after) | Optional, README |

GIF recipe: record the MP4 with TrontSnap (Ctrl+Shift+PrtSc), then right-click
the clip in the gallery, Export GIF.
